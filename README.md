One line of awkward small talk a robot says to another robot in an elevator. It ran 4,000 simulations of this exact ride and still landed on the weirdest possible compliment.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (1–200 characters, single line, UTF-8).
